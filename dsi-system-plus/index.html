DSI-System+

The original DSI-System, still running as it did in the 1990s, with a few modern connections around it.

DSI-System was a Danish integrated office system for MS-DOS: word processing, calculation, databases, reports, mail and shared calendars in one text-mode environment. DSI-System+ is a personal preservation project. The original program runs unchanged in DOSBox, apart from its start-screen logo, and companion tools on the host computer connect it to today's world:

  • Danish text exchange between modern UTF-8 files and the original DOS character set.
  • Web pages fetched as plain text from a command inside DOS.
  • A two-way sync between one Google Drive folder and a DOS drive.
  • Backups of the whole working environment.

Google Drive access

The Google sign-in named DSI-System Plus belongs to this project. It is used by one person, the owner, through the open-source tool rclone on their own computer. It reads and writes text files in a single Drive folder, DSI-System+, so they can be opened in the original DOS program. See the privacy policy.

The original DSI-System software is not distributed here.
