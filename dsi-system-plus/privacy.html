Privacy policy

DSI-System Plus · last updated 1 November 2026

Who uses it

DSI-System Plus is a private, non-commercial tool. Its Google sign-in is used only by its owner, on the owner's own computer, to sync the owner's own files. It is not offered to other users.

What it accesses

With the owner's permission, the open-source program rclone uses the Google Drive API to list, read, create, update and move to trash text files in one Drive folder, DSI-System+. Those files are copied to and from the owner's computer so the DOS program DSI-System can open them.

What happens to the data

  • Files stay between the owner's Google Drive and the owner's computer.
  • Nothing is sent to the developer or any other server, and no analytics or tracking are used.
  • Data is not sold, shared or used for advertising.
  • The sign-in token is stored only in rclone's configuration file on the owner's computer.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local rclone configuration removes the stored token.

Contact

Questions can be raised through github.com/grinoir.
